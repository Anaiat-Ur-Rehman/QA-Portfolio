# Bug Report Sample

- **Bug ID:** BUG-001
- **Title:** Login button unresponsive on mobile view
- **Severity:** High
- **Priority:** High
- **Environment:** Chrome Browser (Mobile View), Android

### Description:
When a user opens the login page on a mobile device and clicks the "Sign In" button, the button does not trigger any action.

### Steps to Reproduce:
1. Open the application URL on a mobile device.
2. Enter valid login credentials in the respective fields.
3. Tap the "Sign In" button.

### Expected Result:
The user should be logged into their account immediately.

### Actual Result:
The button shows a loading state briefly, but nothing happens, and the user remains on the login page.
